# แบบสอบถามความพึงพอใจการเรียนย่ำข่าง (25-26 กรกฎาคม 2569)

ฟอร์มสำหรับเก็บข้อมูลผู้เรียน + ความพึงพอใจ → ใช้ทำประกาศนียบัตรอัตโนมัติ

## ฟีเจอร์

- **คำนำหน้าชื่อ/ยศ**: นาย, นาง, นางสาว, พท., พท.ป., พ.ต., ดร., ผศ. ฯลฯ
- **ชื่อ-สกุล + อีเมล**: ใช้สำหรับออกประกาศนียบัตรส่งทางออนไลน์
- **แบบสำรวจ 7 ข้อ** (ระดับ 1-5): เนื้อหา, วิทยากร, เอกสาร/สื่อ, สถานที่, ระยะเวลา, การนำไปใช้, โดยรวม
- **ข้อเสนอแนะ** (textarea)
- **ข้อมูลไป Google Sheets** แผ่น "ความพึงพอใจ" อัตโนมัติ
- ธีมเขียวธรรมชาติ + โลโก้อาศรมศรีมงคล + responsive

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | หน้าแบบสอบถาม |
| `style.css` | สไตล์ (ธีมเขียว) |
| `script.js` | ส่งข้อมูลไป Apps Script (JSON) |
| `../Code.gs` | สคริปต์ Apps Script (รองรับทั้งลงทะเบียน + แบบสอบถาม) |

## วิธีติดตั้ง (1 ครั้ง)

1. เปิด Google Sheets → **ส่วนขยาย (Extensions)** → **Apps Script**
2. ลบโค้ดเดิม → วาง **Code.gs** (ไฟล์ในโฟลเดอร์หลัก — รองรับทั้ง 2 ฟอร์ม)
3. บันทึก → **ปรับใช้ (Deploy)** → **นวัตกรรมการปรับใช้แบบใหม่**
   - ประเภท: **Web app** / ดำเนินการเป็น: **ฉัน** / เข้าถึงได้: **ทุกคน (Anyone)**
4. กด **ปรับใช้** → **อนุญาตสิทธิ์** → คัดลอก URL `/exec`
5. นำ URL ไปใส่ใน `script.js` (ตัวแปร `WEB_APP_URL`) — ใช้ URL เดียวกับฟอร์มลงทะเบียน

## ข้อมูลใน Google Sheets (แผ่น "ความพึงพอใจ")

```
วันที่-เวลา | คำนำหน้า/ยศ | ชื่อ | สกุล | อีเมล | Q1-Q7 (คะแนน 1-5) | ข้อเสนอแนะ
```

## ขั้นตอนถัดไป: ประกาศนียบัตรอัตโนมัติ

ข้อมูลในชีต (ชื่อ + ยศ + อีเมล) จะถูกใช้สร้างประกาศนียบัตร PDF และส่งอีเมลอัตโนมัติ
(แผน: Apps Script สร้าง PDF + GmailApp.sendEmail — ฟรี 100%)
