# 🌿 แบบฟอร์มลงทะเบียนผู้สนใจเรียน — อาศรมศรีมงคล

เว็บฟอร์มลงทะเบียนผู้สนใจเรียน (จตุรธาตุ / ย่ำข่าง) — HTML + CSS + JavaScript
ข้อมูลที่กรอกจะ **วิ่งเข้าสู่ Google Sheets อัตโนมัติ** ผ่าน Google Apps Script (ฟรี 100%)

## 📁 ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าฟอร์ม (โครงสร้าง) |
| `style.css` | การออกแบบ (ธีมเขียวธรรมชาติ) |
| `script.js` | ส่งข้อมูลไป Google Sheets |
| `Code.gs` | สคริปต์ฝั่ง Google Sheets (รับข้อมูล) |
| `assets/logo.jpg` | โลโก้อาศรมศรีมงคล |
| `assets/qr_facebook.png` | QR code ลิงก์ Facebook |
| `assets/qr_maps.png` | QR code สถานที่เรียน (Google Maps) |

## 🚀 วิธีติดตั้ง (2 ขั้นตอน)

### ขั้นตอนที่ 1: สร้าง Google Sheets + วางสคริปต์ (ทำใน Google)

1. เปิด **Google Sheets ใหม่** → ตั้งชื่อไฟล์ เช่น `ทะเบียนผู้สนใจเรียน`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` ลงไป
4. กด **บันทึก** (💾) → กด **ปรับใช้ (Deploy)** → **นวัตกรรมการปรับใช้แบบใหม่**
5. ตั้งค่า:
   - **ประเภท:** เว็บแอป (Web app)
   - **ดำเนินการเป็น:** ฉัน (Me)
   - **ผู้ที่เข้าถึงได้:** ทุกคน (Anyone)
6. กด **ปรับใช้** → ระบบจะให้อนุญาตสิทธิ์ → กด **อนุญาต** (Allow)
7. ได้ **URL** รูปแบบ `https://script.google.com/macros/s/XXXX/exec` — **คัดลอกไว้**

### ขั้นตอนที่ 2: ใส่ URL ใน script.js

1. เปิดไฟล์ `script.js`
2. หาบรรทัดบนสุด:
   ```js
   const WEB_APP_URL = "https://script.google.com/macros/s/XXXXXXXXXXXX/exec";
   ```
3. เปลี่ยนเป็น URL ที่ได้จากขั้นตอนที่ 1 ทดสอบดูครับ

- ทุกครั้งที่มีคนส่งฟอร์ม → แถวใหม่ปรากฏทันที (Real-time)

## 🧪 วิธีทดสอบ

1. เปิด `index.html` ในเบราว์เซอร์ (ดับเบิลคลิกไฟล์)
2. กรอกข้อมูลทดสอบ → กด **ส่งข้อมูลลงทะเบียน**
3. เปิด Google Sheets → เห็นข้อมูลโผล่มาทันที ✅

## ⚠️ ข้อควรระวัง

- ต้อง **Deploy ใหม่ทุกครั้ง** ที่แก้ `Code.gs` (กด Deploy > จัดการการปรับใช้ > ✏️ > เวอร์ชันใหม่)
- โหมด `no-cors` ใน script.js ทำให้เบราว์เซอร์ไม่อ่าน response ได้ แต่ข้อมูลส่งถึงชีตแน่นอน (ลองเปิด Sheets ดูได้)
- ฟรีทั้งหมด — ไม่มีค่าบริการใดๆ ทั้งสิ้น
